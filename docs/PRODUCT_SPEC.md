# ClearChoice MVP — specifica consolidata

## Percorso

1. Compatibilità e formulazione
2. Verifica dell’avanzamento
3. Nucleo della scelta
4. Informazione, condizione, supporto o trade-off
5. Scheda finale

## Priorità degli stati

1. Fuori perimetro
2. Struttura da delimitare
3. Informazione determinante
4. Condizione futura
5. Supporto esterno
6. Trade-off
7. Pronto a scegliere

## Correzioni vincolanti

- nessun font remoto obbligatorio;
- nessuna persistenza di testo libero prima del pre-check;
- riapertura ammessa solo con un cambiamento concreto validato.
